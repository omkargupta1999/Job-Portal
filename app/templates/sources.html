LinkedIn

{% if by_adapter.email_alerts %}{{ source_status(by_adapter.email_alerts) }}{% endif %}

LinkedIn has no jobs API for individuals and its User Agreement forbids scraping, so JobHub never connects to LinkedIn. There are two supported ways to bring LinkedIn jobs in:

1 · Automatic: LinkedIn job-alert emails experimental

  1. On LinkedIn, run a job search (e.g. “DevOps Engineer”, India) and switch on Set alert (daily).
  2. For Gmail, create an App Password (Google Account → Security → 2-Step Verification → App passwords).
  3. Add to .env: JOBHUB_IMAP_HOST=imap.gmail.com, JOBHUB_IMAP_USER=you@gmail.com, JOBHUB_IMAP_PASSWORD='app-password', then run docker compose up -d.

JobHub opens the mailbox read-only, reads only mail from jobalerts-noreply@linkedin.com, keeps only the job ID from each link and never follows the sign-in links in the email. Alerts carry title, company and location but no description.

2 · One click per job: the “Save to JobHub” button

Drag this button to your bookmarks bar. When you are viewing a job on LinkedIn, Naukri or any site, select the job description (optional) and click it. JobHub opens with the details filled in.
